# 🛒 Lista de Compra (Shopping List App)

Una aplicación práctica e intuitiva para gestionar tu lista de la compra diaria y organizar tus tareas sin complicaciones.

---

## 🚀 Características Principales (Features)

* **Añadir y Eliminar Elementos:** Agrega productos a tu lista rápidamente y elimínalos cuando ya no los necesites.
* **Marcar como Completado:** Marca los productos que ya has comprado para llevar un control visual claro.
* **Persistencia de Datos:** Tus datos se guardan para que no pierdas tu lista al cerrar la aplicación.
* **Interfaz Limpia y Responsive:** Diseñada para adaptarse a pantallas móviles y de escritorio.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura de la aplicación.
* **CSS3:** Diseños y estilos visuales.
* **JavaScript (ES6+):** Lógica funcional de la aplicación y manipulación del DOM.
