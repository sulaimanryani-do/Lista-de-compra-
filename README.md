# 🛒 Lista de Compra App

Una aplicación móvil moderna desarrollada en **Kotlin** para Android que permite gestionar listas de compras colaborativas en tiempo real. Organiza tus productos por categorías y comparte tus listas con familiares o amigos para que todos estén sincronizados al instante.

---

## ✨ Características Principales (Features)

* **📋 Gestión de Listas:** Crea, edita y elimina múltiples listas de compras según tus necesidades.
* **🏷️ Categorización de Productos:** Añade productos agrupados por categorías para hacer tus compras de forma organizada y rápida.
* **☑️ Control de Compras:** Marca (check) los productos a medida que los compras o elimínalos cuando ya no sean necesarios.
* **🔄 Sincronización e Interacción en Tiempo Real:** Comparte tus listas con otras personas. Cualquier cambio (añadir, editar, marcar o eliminar) se actualiza automáticamente para todos los usuarios que comparten la lista.

---

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** [Kotlin](https://kotlinlang.org/)
* **Plataforma:** Android SDK
* **Arquitectura:** MVVM (Model-View-ViewModel)
* **Base de Datos / Backend:** Realtime Database / Firestore (Sincronización en tiempo real)
